# 叙事、图表与成品交付

导航：第 1–2 节为故事线与页级论证；第 3–5 节为图表、视觉与来源；第 6–7 节为编辑范围和成品验证。

## 1. 用一个决策组织整份报告

把任务压缩为：谁需要在什么时间，依据哪些约束，在什么选项之间做什么决定。
依据会议时长、阅读方式和决策复杂度决定页数；不要为了显得完整堆叠框架或背景。
先写故事线，再制作页面。对每页追问：删掉这一页，会损失哪条判断依据？

建议的信息顺序：

1. **结论总览**：建议、关键证据、主要不确定性、需要批准或讨论的事项。
2. **问题与边界**：目标、用户或客户、地理范围、时间、评估对象与比较口径。
3. **判断依据**：最影响决策的市场事实、用户任务、竞争、经济性与能力差距。
4. **选项比较**：共同尺度下的优缺点、可行进入路径、重要反证与适用条件。
5. **行动与下一次决策**：谁执行什么验证、需要什么资源、何时依据什么结果继续或停止。
6. **附录**：详细数据、计算、评分锚点、来源与必要的方法说明。

以上是可裁剪的逻辑顺序，不是强制目录。纯经营复盘或用户指定的结构可以不同。
封面之后的第一张实质内容页应让决策者看到主张及依据；不要让他先读多页背景。
多方案比较时，把评分、证据置信度与建议动作分开显示，避免把高分直接解释为批准投资。

## 2. 先写页级论证，再选择图形

每页先定义五项：**结论标题、支持证据、图形关系、决策含义、来源定位**。
标题陈述一个完整判断；内容必须实际支持这个判断。证据只证明相关时，不写因果标题。
标题的确定程度与证据一致；把条件、范围或关键限制留在标题或靠近图表的位置。

虚构示例，仅示范表达：

| 弱标题 | 更有效的标题 | 内容要求 |
|---|---|---|
| 用户情况 | 付费用户减少，但客单价上升抵消了收入压力 | 同期用户、收入及口径一致的客单价计算 |
| 市场空间 | 在可触达渠道约束下，首年销售空间取决于转化率 | 可触达客群、转化假设及敏感性区间 |
| 产品对比 | 方案甲更适合快速验证，方案乙需要先解决安装成本 | 同一任务与同一评估锚点下的比较 |
| 下一步 | 先验证重复使用，再决定是否投入量产 | 验证设计、周期、成本、阈值与决策责任人 |

不要把一句话拆成许多装饰卡片。优先让证据之间的关系一眼可见。
页内只保留一个中心判断；确实存在两个独立判断时拆页。
复杂推导放附录，但在正文保留足以评估结论的关键分母、假设和限制。

## 3. 根据关系选择图表

| 要解释的关系 | 优先图形 | 必须保留的信息 |
|---|---|---|
| 类别大小或排名 | 横向条形图、点图 | 单位、时间、排序规则；柱形长度从零起 |
| 时间趋势 | 折线图、分组柱形图 | 连续时间刻度、观测频率、缺失值 |
| 实际与预测 | 同轴趋势图，分段样式 | 清晰的分界、假设、区间；不拼接为一条确定事实 |
| 总量如何变化 | 瀑布图 | 起点、终点、可加总的增减项与计算校验 |
| 组成及变化 | 堆叠条形图或百分比堆叠图 | 总量或分母、互斥且穷尽的类别 |
| 两个量的关系 | 散点图 | 两轴单位、样本、异常点；不暗示已证实因果 |
| 范围与不确定性 | 区间图、敏感性表 | 上下界来源、变动参数、其他条件 |
| 多维选项比较 | 简洁表格、热力表 | 统一锚点、未知项、权重与置信度 |
| 流程、因果假设或能力依赖 | 流程图、逻辑图 | 方向、节点定义、证据与假设的区别 |
| 资源配置与阶段承诺 | 阶段表、里程碑图 | 负责人、资源、进入与退出条件 |
| 单个重要数值 | 大数字加直接解释 | 指标、期间、分母或比较基准、来源 |

不要为装饰使用三维图、无意义仪表盘或雷达图。饼图仅适用于少量、互斥的整体组成。
非零起点、对数轴或双轴确有必要时，明确标注，并确认读者不会误判差异。
相似小图保持相同刻度；若必须不同，在图面清楚说明。零值与缺失值不得混用。
比例必须标明分母；“增长了 5%”与“增长了 5 个百分点”不得混写。
不要从图像视觉长度反推精确数据。无法取得底层数据时，标记近似或只表达定性关系。

## 4. 建立一致、克制的视觉系统

在用户未提供模板时，采用适合阅读场景的统一宽屏网格、字体层级、边距和页脚。
选用可用且支持所需语言的字体；跨设备可用性比罕见字体更重要。
用一种主色组织结构、一种强调色突出判断，用中性色承载背景；红绿配色增加文字或形状标识。
同类概念使用同一颜色；不同图中的颜色不要任意改变含义。
保持标题、正文、数据标签、注释的层级清楚。避免为塞入内容不断缩小字号。
背景留白服务于分组与阅读；图标只在帮助辨认类别时使用。
“咨询式”指结论先行、证据充分和版式纪律，不复制第三方专有模板、标识或声称官方背书。

长表先分清用途：正文展示影响决策的关键列，完整明细进入附录。
必须跨页时重复表头、单位与共同口径，保持列宽和排序一致，并写清续表关系。
不要用截图缩小整张表；也不要截断句子、来源标题或网址来强行塞进页脚。

## 5. 来源靠近主张，细节可追溯

为关键事实、图表和计算分配稳定来源编号，并在相关页面就近标注。
页脚写清来源机构、文档或数据名称、期间以及必要的计算说明。
演讲备注或附录提供完整链接、页码或章节、访问日期、原始指标定义及局限。
内部材料标记来源类型及访问限制；公开交付前检查其公开授权。
同一页包含多个口径或来源时，标出每个来源支持的具体数据，而非堆放一串链接。
对计算结果说明公式和输入；对假设情景明确标记“情景测算”，不包装成市场预测。

## 6. 生成可编辑成品并守住修改范围

先使用当前环境提供的演示文稿能力及其规范；没有对应能力时选用可用的通用工具。
文本、表格和精确数据图优先使用原生可编辑对象，并保留底层数据。
照片或必要插图可使用图片；不要把整页栅格图冒充可编辑 PPT。
使用生成式图片表达氛围或概念，不用它生成必须准确的数字、坐标、流程文字或数据图。
需要导出到其他平台时，检查字体、图表、链接、备注、裁切和透明度的转换结果。
若只能生成页面内容或静态 PDF，明确交付范围，不声称已创建可编辑 PowerPoint。

修改既有报告时，先确认最新版、用户指定页和要求保留的结论、模板与对象。
纯排版任务不擅自重写已批准战略；发现实质矛盾时单独指出，业务内容修正限于用户已授权的范围。
用户要求从零表达时，删除前任版本、修改记录和“本次新增”等叙述，包括备注与附录。
不要为小修改重做所有页面；对变更对象检查局部影响，并检查最终全稿的一致性。

## 7. 对最终文件做三层验证

**内容层**：核对主张与证据、计算与单位、评分逻辑、图表与文字的一致性；检查结论是否超出证据。
**文件层**：核对文件可解析、页数和顺序、关键对象及备注、来源链接、导出与保存状态。
**视觉层**：将最终版本每一页完整渲染后逐页检查，而非只看缩略图或未导出的制作画布。

逐页检查标题换行、重叠、裁切、字号、表格末行、脚注、图例、轴标签、图片比例和留白。
总览联系表用于发现整体节奏与风格问题；细节仍需查看单页原尺寸渲染。
修复后重新渲染受影响页，并确认交付文件就是已验证版本。
存在实际演示环境时检查关键动画与播放；没有该环境就如实说明未验证的部分。
不要把“结构校验通过”写成“已经在 PowerPoint 中打开测试”，也不要把来源字段齐全写成事实已核实。
交付时说明文件、主要产出、实际完成的验证及影响使用的局限；避免冗长制作日志。
